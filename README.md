# 军棋

Windows 离线两人暗棋游戏，可自行布阵，与职业或地狱难度的电脑对战。

## 下载

在 [Releases](https://github.com/zwbdwdc/junqi/releases/latest) 点击 `军棋3.0.5.exe` 附件，下载后双击运行。GitHub 会移除附件文件名里的中文，因此保存的文件名是 `3.0.5.exe`，可改为 `军棋3.0.5.exe`。仓库公开，源码和游戏附件均可查看、下载；游戏运行不需要登录或联网。

每次游戏更新都在本仓库新增一个带版本号的 Release，包含更新说明和对应程序。旧版发布记录保留，“最新版”链接始终指向最新正式发布。

## 玩法

- 自由摆放棋子，也可随机布阵、保存和载入阵型。每局随机决定先手，双方机会各为50%。
- 系统裁判吃子，双方按暗棋信息对弈；电脑只能从公开走法和交战结果推断对手身份。
- 支持行营、铁路，以及本项目采用的地方玩法：只有工兵能进入两个山界，入山受保护；工兵进山或沿铁路转弯会明置。
- 右键标记对方暗子；保留战场记录，对局结束后可明棋逐步复盘。
- 对局、阵型和长期学习记录保存在本机，关闭后仍保留。

地狱难度每步约 5 秒，职业约 0.9 秒。程序仍有策略不足，尚未达到“地狱对职业 20 局真实终局、至少 19 胜”的棋力标准。

## 本地开发

使用 Windows、Node.js 24 和 pnpm，依赖版本由 `pnpm-lock.yaml` 锁定。

```powershell
pnpm install --frozen-lockfile
# 安装 Electron 运行时；即使 pnpm 跳过了依赖安装脚本，也可显式完成此步。
node node_modules/electron/install.js
pnpm start
```

运行全部单测，无需启动图形界面：

```powershell
node --test tests/*.test.mjs
```

构建 Windows 便携程序：

```powershell
pnpm package
```

构建产物默认位于 `release/军棋暗战-便携版.exe`。发布时使用程序真实版本命名，例如 `军棋3.0.5.exe`；先校验再上传，不给旧二进制更名冒充更新。

`dist/` 是可编辑的运行源码。`main.cjs` 与 `preload.cjs` 提供桌面入口和保存桥；`tests/fixtures/` 是必要的匿名回归局面。

仓库还保留了单测依赖的自对弈与验证工具，使用方式见 [自对弈说明](benchmarks/README.md)。复盘交互检查可运行 `node_modules/electron/dist/electron.exe qa-replay-controls.cjs`，随机先手检查使用 `qa-first-turn.cjs`，启动恢复检查使用 `qa-startup-restore.cjs`，均使用隔离资料目录。完整本机发布流程依赖未上传的历史证据目录，不能直接运行 `finalize-update.mjs` 来重建那些报告。新的棋力评估需单独冻结版本并保留失败、和棋和未完局，不能把软件测试通过当作棋力达标。
